# Heather Fielding Website

Responsive one-page marketing website for a California Certified Studio Teacher and Child Labor Compliance Professional.

## Run locally

Open `index.html` directly, or use a simple local server:

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.
